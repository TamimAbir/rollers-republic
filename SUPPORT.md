## Getting Help

### For Users

1. **Check the documentation** — Most common questions are answered in the README and template guide
2. **Search existing issues** — Look for similar problems on GitHub
3. **Open a GitHub Issue** — Use the issue template for bug reports or feature requests

### For Developers

1. **Read CONTRIBUTING.md** — Follow the contribution guidelines
2. **Check the architecture docs** — Understand the system design before making changes
3. **Run quality gates** — Ensure `npm run lint`, `npm test -- --run`, and `npm run build` pass
